artifact-vault

Every Claude artifact, kept, sorted, searchable.

Copies every Claude artifact into one private git repo, one branch per app and kind (features, guides, screenshots, slides, docs) with an images branch for generated test pictures. Keys found in a page are replaced on the way in and reported by kind, never printed. Then it searches the vault and compares it against the current session, a requested feature list, an uploaded file, or the live artifact list. Zero dependencies: Node and git.

Use when: you want to save, back up or organise Claude artifacts, find an old deck, guide or generated picture, or check whether something is already documented.

How it works

1. SaveClaude lists and downloads your artifacts; ingest sorts them into branches.
2. SearchImages, slides, features, guides, screenshots and docs, by app, date or words.
3. CompareAgainst a session, a feature list, an upload, or what is live.

Install

git clone https://github.com/Violinet-tech/artifact-vault ~/.claude/skills/artifact-vault

Works in Claude Code and any harness that reads the SKILL.md format. The markdown is also plain docs, readable without an agent. Then ask: "Save all my artifacts into a vault."
